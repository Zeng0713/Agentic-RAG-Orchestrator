## 什么是 Agent
Agent 是一种能够根据目标进行推理、选择工具并执行任务的程序。
一个常见的 Agent 系统由大语言模型、工具、执行循环和上下文管理组成。不同项目的执行循环复杂度不同，有些只调用一次工具，有些会根据中间结果持续进行多轮工具调用。

## 什么是 RAG
RAG 的全称是 Retrieval-Augmented Generation，即检索增强生成。
它先从外部知识库检索相关内容，再将这些内容提供给大语言模型，
使模型能够结合外部资料回答问题。

## 什么是 Embedding
Embedding 是将文本等数据转换为向量表示的技术。
语义相近的文本在合适的向量空间中通常具有较高的相似度，
因此可以用来实现语义检索。

## 什么是向量数据库
向量数据库可以存储向量及其关联的数据，并支持相似度检索。
在 RAG 系统中，它常用于保存文档文本块的向量和来源信息。

## Agent 的执行循环

在通用 Agent 设计中，执行循环可以协调大语言模型和工具之间的多轮交互；但并非所有 Agent 都实现多轮循环。

在执行循环中，大语言模型会根据当前任务决定下一步行动。
如果需要使用工具，Agent 会执行工具，并将工具结果重新提供给大语言模型。

大语言模型可以根据工具执行结果继续决定下一步操作，
直到任务完成或达到停止条件。

支持多轮循环时，Agent 可以根据中间结果继续推理和行动。较简单的实现也可以只进行一次工具选择、执行工具后生成最终回答。

本项目当前采用后一种方式：模型进行一次工具选择，程序执行返回的工具调用，再由模型生成最终回答；尚未实现持续多轮工具调用。
